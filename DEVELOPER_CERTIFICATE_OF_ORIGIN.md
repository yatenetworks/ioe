# Developer Certificate of Origin (DCO)

This project uses the Developer Certificate of Origin version 1.1 to confirm that contributors have the right to submit their work.

## What you certify

By adding `Signed-off-by: Your Name <your.email@example.com>` to a commit message, you certify that:

1. The contribution was created in whole or in part by you, or you have the right to submit it under the open source license indicated in the file; and
2. The contribution is provided under the terms of that license; and
3. You understand and agree that the project and the contribution are public and that a record of the contribution (including all personal information you submit with it) is maintained indefinitely and may be redistributed consistent with the project license or the open source license(s) involved.

Full text: https://developercertificate.org/version/1/1

## How to sign off

Add a sign-off line to each commit:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Use the `-s` flag with git:

```bash
git commit -s -m "docs: clarify template validation notes"
```

## Pull requests

Every commit in a pull request should include a valid sign-off unless the maintainer explicitly accepts an exception for a trivial fix.

Maintainers may ask you to amend commits that are missing sign-off.
