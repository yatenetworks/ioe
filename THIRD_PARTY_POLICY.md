# Third-Party Content Policy

IOE welcomes references to well-known open tools and clear template dependencies, but third-party content must be used responsibly.

## General rules

When you include third-party code, images, models, brands, logos, or documentation:

- confirm you are allowed to use and redistribute it under the project license
- keep license notices and attribution where required
- document the source URL or package name in the pull request
- prefer official images, packages, and documentation links over unofficial mirrors
- do not copy restricted, confidential, or paywalled material into this repository

## Brands and logos

Do not imply endorsement by other projects or companies.

Use third-party names and logos only when needed for accurate documentation, and follow each project's trademark guidelines when applicable.

Do not present this repository as an official fork, mirror, or replacement of another product unless you have permission.

## Models and assets

Model files and large assets should not be committed to git unless the repository explicitly allows them.

Prefer documenting download steps, checksums, and license terms in template README files instead of bundling restricted assets.

## Dependencies

New dependencies must be justified in the pull request. See [docs/DEPENDENCY_POLICY.md](docs/DEPENDENCY_POLICY.md).

## Review

Maintainers may reject content that creates unclear licensing risk, impersonates another project, or omits required attribution.
